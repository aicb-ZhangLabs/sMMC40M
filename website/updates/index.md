# What's new

New acquisitions are added **monthly**. Each update lists the samples added, their platform,
category and species, the new totals, and the Hugging Face revision to pin for reproducibility.
Frozen releases are never modified in place: every addition is a new version.

Subscribe by watching [releases on GitHub](https://github.com/aicb-ZhangLabs/sMMC40M/releases) or
[the dataset on Hugging Face](https://huggingface.co/datasets/zhang-lab/sMCC40M).
